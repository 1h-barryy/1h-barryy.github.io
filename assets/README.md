# Project assets

- Portfolio project files go in `assets/portfolio/<project-name>/`.
- BarryMade project media lives next to its page, in `barrymade/<slug>/media/`. Name files `<slug>-01.webp`, `<slug>-02.webp`, … in display order, each with an 800px `<slug>-NN-thumb.webp`; slide decks stay `.jpg`. Max 2400px on the long edge. No HEIC or video files in the repo: convert photos to WebP and put video on YouTube.
- Shared CSS, JavaScript, icons, fonts, and site images stay in their existing shared folders.

Thought Path folders: put the hero image in `assets/portfolio/thought-path/hero/`, the nine slides in `assets/portfolio/thought-path/slides/` (for example `slide-01` through `slide-09`), and other images or video in `assets/portfolio/thought-path/media/`.
