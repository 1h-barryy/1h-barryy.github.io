Overview

A browser game inspired by Crossy Road. You move through lanes and avoid obstacles. I changed the whole theme and setting to a magical forest.

How it plays

Movement is one tile per key press, with the arrow keys or WASD. Your score goes up only when you reach a new lane further ahead, and the run ends when you hit an obstacle.

  • Crossings: dodge boulders, thorn wheels and spirit boars
  • Rivers: ride logs, rafts and rare hopping mushrooms
  • Runes: these lanes cycle from quiet to waking to thorns, so cross while they're quiet
  • P pauses, R restarts, and your personal best is saved in this browser

How it was made

It's a static page in plain HTML, CSS and JavaScript with no build step or server, so it runs straight from GitHub Pages. I worked out the overall design and direction in chat with GPT6 Astra, then wrote prompts for Codex to carry them out.

What's next

The game could use more layers, and the art assets could be more polished and detailed.
